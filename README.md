### [Devian — Local Coding-Agent Orchestration Workspace](https://github.com/joseianpatrick/devian-showcase)

**In progress · Personal** | React 19, TypeScript, Python, FastAPI, SQLite

- Built after hitting permission limits with AI coding agents in a local n8n automation setup, where agents in separate Git worktrees couldn’t write files, wasting runs and token credits.
- Runs Claude Code and Codex through their own CLIs using existing Claude Pro and ChatGPT Plus (Codex) subscriptions instead of separately billed LLM API keys.
- Gives each agent attempt its own branch and worktree, routes permission requests to a human, and records diffs, logs and token usage.
- Uses FastAPI, SQLAlchemy and SQLite with a React 19, Vite and Tailwind CSS 4 dashboard for task planning, goals with run and cost budgets, and draft pull requests through the GitHub CLI.

Showcase available above; source currently private.

### [Kalsada — AI-Assisted Group Trip Planner](https://github.com/joseianpatrick/travel_ai_generation)

**In progress · Personal** | Flutter, Supabase, Drift, OpenStreetMap

- Generates day-by-day group itineraries from conversational prompts through a Supabase Edge Function that calls an LLM, keeping provider keys off the client.
- Includes Supabase email/password authentication, a realtime database, private photo storage and an offline cache with a sync outbox.
- AI-assisted build: I set the architecture (MobX stores over repository contracts) and reviewed and corrected the agents’ output.
