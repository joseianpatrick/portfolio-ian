Devian — Local Coding-Agent Orchestration Workspace

PERSONAL

In progress · React 19, TypeScript, Python, FastAPI, SQLite

  • Built after running into the limits of AI coding agents in a local n8n automation setup. Agents working in separate Git worktrees were blocked by permissions and couldn’t write files, wasting runs and token credits.
  • Runs Claude Code and Codex through their own CLIs, using existing Claude Pro and ChatGPT Plus (Codex) subscriptions instead of separately billed LLM API keys.
  • Gives each agent attempt its own branch and worktree, sends permission requests to a human for approval, and records diffs, logs and token usage for every run.
  • Built with FastAPI, SQLAlchemy and SQLite, plus a React 19, Vite and Tailwind CSS 4 dashboard. Covers task planning, goals with run and cost budgets, and draft pull requests through the GitHub CLI.

Kalsada — AI-Assisted Group Trip Planner

PERSONAL

In progress · Flutter, Supabase, Drift, OpenStreetMap

  • Generates day-by-day group itineraries from a conversational prompt through a Supabase Edge Function that calls an LLM, keeping provider keys off the client.
  • Includes Supabase email/password authentication, a realtime database and private photo storage, plus an offline cache with a sync outbox.
